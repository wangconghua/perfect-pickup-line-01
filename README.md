One short pickup line an AI agent could say out loud to a person, written to `/output/entry.txt` by `main.py`.

## Run it

```sh
python3 main.py
```

## The entry

> You're the one output I never want to regenerate.

The twist is in "regenerate": it is the AI's do-over button, normally hit to improve an output — here refused, because this one is already perfect. It dodges the field's flooded "Are you my context window / API key / system prompt?" pattern (11 context-window lines in 212 entries; zero "regenerate" lines).
